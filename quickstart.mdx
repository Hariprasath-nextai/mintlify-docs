## React Quickstart {#react-quickstart}

### Step 1: Get Your API Key

1. Sign up at [NextEVI Dashboard](https://dashboard.nextevi.com)
2. Create a new project and copy your API key
3. Note your Project ID and Config ID from the dashboard

### Step 2: Install the SDK

```bash
npm install @nextevi/voice-react
# or
yarn add @nextevi/voice-react
```

### Step 3: Build Your First Voice Chat

```tsx
import React from 'react';
import { useVoice } from '@nextevi/voice-react';

function VoiceChat() {
  const { connect, disconnect, readyState, messages, isRecording } = useVoice();

  const handleConnect = async () => {
    await connect({
      auth: {
        apiKey: "oak_your_api_key_here",
        projectId: "your-project-id",
        configId: "your-config-id"
      }
    });
  };

  return (
    <div style={{ padding: '20px', maxWidth: '600px' }}>
      <div style={{ marginBottom: '20px' }}>
        <button 
          onClick={readyState === 'connected' ? disconnect : handleConnect}
          disabled={readyState === 'connecting'}
        >
          {readyState === 'connected' ? 'Disconnect' : 'Start Voice Chat'}
        </button>
        
        <div style={{ marginLeft: '10px', display: 'inline' }}>
          Status: {readyState} {isRecording && '🎤'}
        </div>
      </div>

      <div style={{ border: '1px solid #ccc', padding: '10px', height: '300px', overflowY: 'scroll' }}>
        {messages.map(message => (
          <div key={message.id} style={{ marginBottom: '10px' }}>
            <strong>{message.type === 'user' ? 'You' : 'AI'}:</strong> {message.content}
            {message.metadata?.emotions && (
              <div style={{ fontSize: '12px', color: '#666' }}>
                Emotion: {Object.entries(message.metadata.emotions)
                  .reduce((a, b) => a[1] > b[1] ? a : b)[0]}
              </div>
            )}
          </div>
        ))}
      </div>
    </div>
  );
}

export default VoiceChat;
```

### Step 4: Test It Out

1. Replace the placeholder credentials with your actual API key, project ID, and config ID
2. Run your React app: `npm start`
3. Click "Start Voice Chat" and start speaking!

<Tip>
The AI will detect your emotions and respond accordingly. Try speaking with different tones to see emotion recognition in action.
</Tip>

## WebSocket Quickstart {#websocket-quickstart}

For non-React applications or when you need direct WebSocket control:

### Step 1: Establish Connection

```javascript
const ws = new WebSocket(
  `wss://api.nextevi.com/voice/websocket/${connectionId}?api_key=oak_your_api_key&config_id=your_config_id&project_id=your_project_id`
);

ws.onopen = () => {
  console.log('Connected to NextEVI');
  
  // Configure session
  ws.send(JSON.stringify({
    type: "session_settings",
    timestamp: Date.now() / 1000,
    message_id: "settings-1",
    data: {
      emotion_detection: { enabled: true },
      turn_detection: { enabled: true }
    }
  }));
};
```

### Step 2: Send Audio and Handle Messages

```javascript
// Handle incoming messages
ws.onmessage = (event) => {
  const message = JSON.parse(event.data);
  
  switch (message.type) {
    case 'transcription':
      console.log('User said:', message.data.transcript);
      if (message.data.emotions) {
        console.log('Emotions:', message.data.emotions);
      }
      break;
      
    case 'audio_output':
      // Play TTS audio
      playAudio(message.data.audio);
      break;
      
    case 'llm_response_chunk':
      console.log('AI response:', message.data.content);
      break;
  }
};

// Send audio data
function sendAudioChunk(audioData) {
  ws.send(JSON.stringify({
    type: "audio_input",
    timestamp: Date.now() / 1000,
    message_id: `audio-${Date.now()}`,
    data: {
      audio: btoa(audioData), // Base64 encode PCM data
      sample_rate: 24000,
      channels: 1,
      encoding: "linear16"
    }
  }));
}
```

## Common Issues

<AccordionGroup>
  <Accordion title="Microphone not working" icon="microphone-slash">
    - Ensure HTTPS is enabled (required for microphone access)
    - Check browser permissions for microphone access
    - Test with `navigator.mediaDevices.getUserMedia({ audio: true })`
  </Accordion>
  
  <Accordion title="Connection fails" icon="wifi-slash">
    - Verify your API key starts with `oak_`
    - Check that your project ID and config ID are correct
    - Ensure you're connecting to the right WebSocket endpoint
  </Accordion>
  
  <Accordion title="No audio output" icon="volume-mute">
    - Check browser audio permissions
    - Verify TTS is enabled in your configuration
    - Test with different browsers (Chrome recommended)
  </Accordion>
</AccordionGroup>
